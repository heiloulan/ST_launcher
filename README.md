# ST Launcher（酒馆直装版）

在 Android 手机上直接运行 SillyTavern，无需安装 Termux 或手动部署运行环境。

支持 **Android 8.0 及以上、arm64 架构**的设备。当前代码版本为 **0.27.3**。

[下载 APK](https://github.com/heiloulan/ST_launcher/releases/latest) · [所有版本](https://github.com/heiloulan/ST_launcher/releases) · [本次更新说明](.github/RELEASE_NOTES.md)

安装包内置 SillyTavern **1.18.0**、Node.js **24.18.0**、酒馆助手 **4.9.5** 和提示词模板 **1.15.16.0**。预装扩展使用固定版本，随应用更新。

首次使用时，从下载页面的 Assets 中选择 `.apk` 文件，安装并打开。应用会自动准备运行环境，随后进入酒馆。聊天使用的模型服务和 API 密钥需要自行配置。

- **升级**：直接安装新版 APK 覆盖旧版即可，无需卸载。升级前建议在“后台功能项”中导出完整备份。
- **备份与导入**：“后台功能项”提供完整备份导出和备份导入。导入会替换当前酒馆数据，请先保存需要保留的内容。
- **字号**：在酒馆主题设置中调整“字体比例”。网页字号由酒馆统一控制，原生界面继续跟随系统字号。
- **后台运行**：需要长时间在后台生成时，可从原生右上角菜单打开“后台运行提示”，按需调整系统电池设置。实际后台运行效果取决于系统限制。
- **排查问题**：“后台功能项”提供扩展安装修复和服务器日志。页面无法打开时，也可以从原生菜单查看日志。

酒馆无法启动、无法正常导出数据时，可使用独立的[救援 APK](https://github.com/heiloulan/ST_launcher/releases/tag/rescue-0.27.3)，操作步骤见[救援使用指南](docs/RESCUE.md)。当前救援包支持本项目同签名的 **0.27.3 及更早版本**；导出数据后，可直接覆盖安装回 0.27.3 正常版。救援前请勿卸载原应用或清除数据。

# 旧版数据救援工具

用于旧版酒馆无法启动、无法正常导出备份时，读取并导出应用内保留的用户数据。安装后会进入专用救援界面，不启动 SillyTavern，也不修改被导出的源文件。

[下载救援 APK](https://github.com/heiloulan/ST_launcher/releases/download/rescue-0.26-test1/ST-Launcher-rescue-test1.apk) · [独立 Release 页面](https://github.com/heiloulan/ST_launcher/releases/tag/rescue-0.26-test1)

当前救援包为 **0.26-rescue-test1（code 27）**，面向本项目同签名的 **0.26 及更早版本**。它与正常版使用相同的应用身份，会覆盖现有安装；不能通过常规安装覆盖 **0.27 及以后的版本，包括 0.27.3**。

**请勿先卸载原应用，也不要清除应用数据。** 待救援的数据保存在原应用内，卸载或清除数据会使救援工具失去读取对象。如果安装提示版本降级或签名不符，请停止，不要通过卸载来绕过。

使用步骤：

1. 下载 `ST-Launcher-rescue-test1.apk`，直接覆盖安装到需要救援的旧版酒馆上。
2. 打开“酒馆直装版 · 数据救援”，等待“新版数据”和“旧版数据”的检查完成。这两个名称表示不同的数据目录布局。
3. 对显示“已找到”的目录，点击对应的“导出新版数据”或“导出旧版数据”。如果两个目录都有数据，请分别导出并保留两份备份。
4. 在系统文件选择器中选择保存位置，例如“下载”目录。导出期间保持救援应用在前台，等待出现“导出成功”。备份文件格式为 `.tar.gz`。
5. 妥善保存备份后，下载并直接覆盖安装 [0.27.3 或更高版本的正常 APK](https://github.com/heiloulan/ST_launcher/releases/latest)，恢复正常酒馆界面，无需卸载救援版。
6. 先查看原聊天、角色等数据是否已经正常显示；需要恢复备份时，再通过“后台功能项 → 导入备份”选择导出的 `.tar.gz` 文件，无需解压。导入会替换当前数据，两份目录备份不会自动合并。

救援包只导出选定的用户数据目录，目录之外的启动配置和全局扩展不在备份中。如果检查或导出失败，请保留原应用、已有备份和界面的错误信息；失败生成的文件不要用于恢复。

该工具作为旧版备用工具独立发布，不随正常版更新。日常备份请使用正常版“后台功能项”中的“导出完整备份”。
